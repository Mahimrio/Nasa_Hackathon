## 1. Challenge Capability Architecture

The core capability answering *“Be An Earth System Trend Detective!”* is implemented in `trend_explorer/analysis.py` and rendered at `/trends`:

### 1.1 What is Changing?
- **Primary Variable:** Total pre-monsoon precipitation accumulation ($PRCPTOT_{AM}$, April 1 – May 31).
- **Secondary Variable:** Heavy rainfall storm day count ($R50mm_{AM}$, days with daily rainfall $\ge 50\text{ mm/day}$).
- **Data Source:** NASA GPM IMERG Final Run V07 (`GPM_3IMERGDF`) daily gauge-calibrated precipitation (2001–2025).

### 1.2 Where is it Changing?
- The spatial domain encompasses the steep transboundary Meghalaya headwater catchments and the northern Surma-Kushiyara Haor basin (23.5°N–26.0°N, 91.0°E–93.5°E), divided into HydroSHEDS hydrological sub-basins.
- Indicators are evaluated **cell-first** on the native 0.1° GPM grid before area averaging, preventing spatial dilution of localized convective storm bursts.

### 1.3 How Much is it Changing?
- Change rate is quantified using the non-parametric **Theil-Sen robust slope estimator** ($\beta$, mm/year or days/year).
- Analytical 95% confidence intervals are computed via Sen-Kendall rank bounds, providing an explicit measure of statistical uncertainty.

### 1.4 Is it Statistically Significant?
- Evaluated via the **Modified Mann-Kendall test** (Hamed & Rao 1998) with variance correction factor $\text{Var}^*(S)$ accounting for empirical lag-1 serial autocorrelation.
- Null hypotheses and non-significant trends ($p > 0.05$) are reported transparently without cherry-picking.

## 2. Step-by-Step Live Demo Instructions for Reviewers / Judges

Follow these steps to demonstrate the full application workflow from a clean checkout:

### Step 1: Launch Local Application
```bash
# Terminal 1: Launch frontend dev server
cd ui && npm run dev
# Browser opens at http://localhost:3000
```

### Step 2: Executive Triage & Provenance Notice (URL: `/`)
1. Observe the prominent top banner:
   > *"Synthetic demonstration data — rainfall, river levels, and SWOT-shaped values were generated by this project. They are not NASA or BWDB/FFWC observations; displayed metrics do not establish forecast skill."*
2. Inspect the **5-Second Executive Triage Strip**:
   - Current Harvest Flag status: High-contrast badge.
   - Modeled Stage at Kanaighat: Current water level vs 13.20m danger level.
   - Upstream Meghalaya Rainfall: Last 6 hours accumulation.
   - Recommended Action: Advisory cut recommendation in English or Bangla.

### Step 3: Interactive Hydrograph Replay (URL: `/forecast` or `/dashboard`)
1. Navigate to `/forecast`.
2. Inspect the 3-line hydrograph:
   - **Solid Teal Line:** Simulated river stage from 4-subreach Muskingum-Cunge routing.
   - **Shaded Teal Fill:** $\pm 0.18\text{ m}$ analytical error propagation envelope.
   - **Amber Dashed Line:** 13.20 m PWD Danger Level benchmark.
   - **Inverted Top Hyetograph:** Half-hourly GPM IMERG rainfall.
3. Drag the timeline replay scrubber across April 10–14:
   - Watch the flood wave propagate down the Surma corridor.
   - Note the causal Harvest Flag transition from GREEN $\to$ AMBER $\to$ RED as water crosses 13.20m.

### Step 4: Geographic Reach Map (URL: `/dashboard`)
1. Click on the Leaflet River Map panel.
2. Toggle between **Geographic (Positron Leaflet)** and **Schematic** views.
3. Observe the authentic 1,719-vertex river meander paths extracted from OpenStreetMap relations (`5904030` and `5904029`).
4. Click on Reach `22211000011` (Kanaighat) to open the **Reach Inspector Modal**, displaying width ($160\text{ m}$), bed elevation ($5.80\text{ m}$), and calibrated Manning roughness ($n = 0.046$).

### Step 5: Haor Rainfall Trend Explorer (URL: `/trends`)
1. Click the **"Trend Explorer"** link in the navigation header.
2. Inspect the fail-closed UI state:
   - When verified mission granules are awaiting download, the UI clearly displays:
     > *"Data unavailable: Upload or ingest a provenance-verified REAL IMERG Final extract; no synthetic trend result is shown."*
   - Explains that trend findings describe historical multi-decadal shifts only and do not predict individual daily floods.
