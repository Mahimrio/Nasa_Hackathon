# RISK REGISTER — HydroSense-SWOT

This risk register guards against the technical traps, vibe-coding errors, and hackathon failure modes cataloged in `SOLUTION_ARCHITECTURE.md v3.0` and `STEERING_GUIDE_FINAL.md`.

---

| # | Risk Description | Early Warning Sign | Built-in Safeguard | Owner | Status |
|---|---|---|---|---|---|
| **R-01** | **SWOT slope noise exceeding physical signal** (Surma slope $\approx 10^{-5}$) | Negative or absurdly large Manning discharge; unphysical $n$ values | Explicit filter: $\text{slope2} > 2 \times \text{slope\_u}$ and $\text{slope2} > 10^{-5}\text{ m/m}$. Unreliable reaches dropped or hatched on map. | R3 Hydrology | **ACTIVE / MITIGATED** |
| **R-02** | **Manning $n$ optimizer escaping physical boundaries** | Scipy returns $n < 0.025$ or $n > 0.10$ | Enforced `scipy.optimize.minimize_scalar(..., bounds=(0.025, 0.10), method='bounded')` with assertion test. | R3 Hydrology | **RESOLVED & TESTED** |
| **R-03** | **IMERG orographic precipitation overestimation** | Flash flood alert triggers too early or produces false positives | Stated transparently in Limits Panel; calibration against downstream gauge absorbs systematic bias; PBIAS reported. | R3 Hydrology | **MITIGATED** |
| **R-04** | **Timezone double-conversion (BST to UTC shifted twice)** | Timestamps shifted by 12 hours (`BST-12`); peak misaligned | Localize to UTC once at ingestion: `pd.to_datetime(..., utc=True)`. Assert all timestamps are timezone-aware. | R4 Data | **RESOLVED & TESTED** |
| **R-05** | **SWOT Reach ID float64 truncation** (11-digit integer truncated in CSV) | `22211000011` becomes `2.2211e+10`, dropping the last reach digit | Explicitly specify `dtype={'reach_id': str}` in all file readers. Never store reach IDs as floats. | R4 Data | **RESOLVED & TESTED** |
| **R-06** | **Sentinel fill values (`-999999.0`) treated as valid WSE** | Absurd negative depths; mean stage drops to negative hundreds | Custom sanitizer replacing all values $\le -9990.0$ with `np.nan` prior to any calculation. | R4 Data | **RESOLVED & TESTED** |
| **R-07** | **Venue WiFi outage during demo or judging** | Live API fails with timeout / 401 / 429 during presentation | Architecture enforces offline fixtures first (`data/fixtures/`). Pipeline operates 100% offline with zero live network reliance. | R5 Backend | **RESOLVED & TESTED** |
| **R-08** | **Team over-claiming SWOT as "real-time flood predictor"** | Presenter claims SWOT warns in real-time; judges penalize Validity | Permanent Limits Panel on UI states SWOT is 21-day orbit and provides offline geometry; lead time comes from IMERG rainfall routing. | R8 Storyteller | **MITIGATED IN SCRIPT** |
| **R-09** | **Over-precision on performance metrics signaling fake data** | Displaying metrics with 6 decimals (e.g. `NSE = 0.742918`) | Formatted explicitly to 2 decimal places (`f"{nse:.2f}"`) in all UI widgets and scripts. | R9 Compliance | **RESOLVED & TESTED** |
| **R-10** | **Uncited third-party data or missing license** | Judge checks repo, finds missing license or citations; nomination revoked | MIT License file in repo; comprehensive `SOURCES.md` claims ledger; References block on NASA project page. | R9 Compliance | **MITIGATED** |
| **R-11** | **Numerical instability in Muskingum-Cunge routing ($C_0 < 0$)** | Artificial precursor dip in river stage prior to flood rising limb | River corridor segmented into 4 sub-reaches ($K_{sub} \approx 6.5\text{ h}$) ensuring $\Delta t$ scaling; outflow lower bounded by baseflow ($90\text{ m}^3\text{/s}$). | R3 Hydrology | **RESOLVED & TESTED** |
| **R-12** | **Timestamp precision mismatch in merge (`datetime64[us]` vs `datetime64[ns]`)** | Pandas `MergeError: incompatible merge keys` crashing validation | Harmonized all internal simulation and observation timestamps to `datetime64[ns, UTC]` in `align_sim_obs`. | R4 Data | **RESOLVED & TESTED** |
| **R-13** | **Frontend metric hardcoding & visual drift from pipeline outputs** | UI shows different numbers than scientific report | All UI metric cards, tooltips, and limits are dynamically computed from `metrics_summary.json` with 0 hardcoded numbers. | R6 Frontend | **RESOLVED & TESTED** |
| **R-14** | **Color vision deficiency (CVD) illegibility on flood maps** | Judges or users with deuteranopia cannot distinguish warning levels | Applied mathematically uniform, CVD-safe Cividis colormap scale across river reaches and legends per Crameri et al. (Nature 2020). | R7 UX | **RESOLVED & TESTED** |
| **R-15** | **Baseline comparison metric discrepancy in validation scripts** | `validation_report.py` passes `df_sim` twice; `run_pipeline.py` hardcodes `lead_steps=48` | Documented as unresolved under active audit in all docs; comparative claims frozen pending dedicated re-benchmarking task (WO-016). | R9 Compliance / R3 Hydrology | **ACTIVE / UNDER AUDIT** |
| **R-16** | **Pre-supposing or fabricating trend outcomes in Trend Explorer** | Team assumes increasing rainfall or statistical significance before executing code | Enforced empirical-first protocol: Sen's slope and Modified Mann-Kendall (Hamed & Rao 1998) test executed strictly on genuine GPM IMERG Final Run data; non-significant or null results reported honestly. | R3 Hydrology | **MITIGATED IN DESIGN** |
| **R-17** | **Confounding climatological trends with real-time flood prediction** | Presenter claims rainfall trends prove worsening floods or predict next flood date | Strict architectural decoupling: Module 1 (operational 24-48h warning) and Module 2 (decadal climatology) answer different questions; explicit negative claims in limits panel. | R8 Storyteller / R9 Compliance | **MITIGATED IN DOCS** |
| **R-18** | **Challenge-fit gap on multi-variable selection prompt** | Official Trend Detective prompt asks to "select variables", while MVP is rainfall-only | Declared challenge alignment as PROVISIONAL; clearly defined rainfall-first MVP scope; planned secondary variable (GLDAS soil moisture) ready as extension upon official resource release. | R0 Scope Guardian | **ACTIVE / PROVISIONAL** |
| **R-19** | **Silent generation of synthetic records in climatology data paths** | Pipeline falls back to random/synthetic numbers when Earthdata is unreachable | Strict fail-closed protocol in `ingest_imerg_daily`: exit code 1 if NASA Earthdata granules missing; zero synthetic series in `data/trends/`. Synthetic records restricted exclusively to unit tests. | R4 Data / R9 Compliance | **MITIGATED IN SPEC** |
| **R-20** | **Incomplete seasonal coverage biasing accumulation and storm counts** | Missing days in April–May scaled up or zero-filled, distorting trend slope | 100% complete season rule enforced: exactly 61/61 calendar days required for primary 2001–2025 analysis; sensitivity years with missing days reported as bounded intervals $[PRCPTOT_{\min}, PRCPTOT_{\max}]$. | R3 Hydrology / R4 Data | **MITIGATED IN SPEC** |
